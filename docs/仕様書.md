# StationAlarm アプリケーション仕様書

**バージョン**: 1.0  
**対象プラットフォーム**: Wear OS (Android 11 以上)  
**最終更新**: 2026-04-25

---

## 1. アプリケーション概要

### 1.1 目的

ユーザーが指定した駅に近づいたときに振動と通知で知らせる Wear OS スマートウォッチアプリ。電車での移動中に乗り過ごしを防止する。

### 1.2 基本仕様

| 項目 | 値 |
|------|-----|
| アプリ名 | 駅近振動通知 (StationAlarm) |
| パッケージ名 | com.example.stationalarm |
| 最小 SDK | 30 (Android 11) |
| ターゲット SDK | 34 (Android 14) |
| 対象デバイス | Wear OS スマートウォッチ |
| 言語 | Kotlin 100% |
| UI フレームワーク | Jetpack Compose (Wear Compose) |

## 2. 機能仕様

### 2.1 機能一覧

| # | 機能 | 概要 |
|---|------|------|
| F-01 | 駅検索 | 入力した駅名を GPS 座標に変換する |
| F-02 | バックグラウンド位置追跡 | フォアグラウンドサービスで継続的に GPS を取得する |
| F-03 | 接近アラーム | 設定距離以内に入ったら振動・通知で知らせる |
| F-04 | 距離しきい値設定 | 通知を行う距離を 100〜2000m の範囲で設定する |
| F-05 | 駅名履歴 | 過去に検索した駅名を最大 5 件保存・表示する |
| F-06 | リアルタイム距離表示 | 目的駅までの現在距離をリアルタイムで表示する |

### 2.2 駅検索（F-01）

- 入力した駅名を Android Geocoder API（日本ロケール: `Locale.JAPAN`）で緯度・経度に変換する
- 「駅」で終わらない入力には自動的に「 駅」を付加してから検索する（例: "渋谷" → "渋谷 駅"）
- 検索はバックグラウンドスレッド（`Dispatchers.IO`）で実行する
- 検索失敗時は「駅が見つかりませんでした...」と UI に表示し、追跡は開始しない

### 2.3 バックグラウンド位置追跡（F-02）

- Fused Location Provider API を使用し、GPS による高精度位置情報を取得する
- 更新間隔: **3 秒**（最小 1 秒）
- 精度: `PRIORITY_HIGH_ACCURACY`（GPS 優先）
- フォアグラウンドサービスとして動作するため、画面を切ってもアプリを閉じても追跡が継続される

### 2.4 接近アラーム（F-03）

接近判定は 2 段階。

| 条件 | 動作 |
|------|------|
| 現在距離 ≤ しきい値 × 0.5 | UI ステータス表示「まもなく到着！」（赤色プログレスリング） |
| 現在距離 ≤ しきい値 | アラーム発火（振動・通知・アプリ前面化）、追跡自動停止へ |

**アラーム発火時の動作（F-03a）**

しきい値到達時に **1 回だけ** 以下を行う。再発火は起こらない。

1. 振動開始（`0.5 秒 ON → 0.5 秒 OFF` を繰り返し、5 秒後に自動停止）
2. 高優先度のアラーム通知を表示（別チャネル）
3. `MainActivity` を直接起動してアプリを前面化
4. リポジトリのメッセージを「目的地に接近しました！」に更新

**音は鳴らさない**: 通知音・通知由来の振動はすべて無効化し、`Vibrator` による明示振動のみで通知する。チャネル側で `setSound(null)` / `enableVibration(false)`、Builder 側で `setSound(null)` / `setDefaults(0)` を設定する。

**追跡の自動停止（F-03b）**

アラーム発火から **8 秒後** にサービスを自動停止する。停止すると以下の状態がリセットされる。

- `isTracking = false`
- `currentDistance = null`
- `stationName = null`
- `message = ""`

ユーザーが画面でアラームを確認できる時間を確保したのち、自動でセットアップ画面に戻る。

**アプリ前面化の仕組み**

電車内などスリープ中の Wear OS デバイスでもアラームを見逃さないよう、複数の手段を併用する。

1. `startActivity()` による直接起動（`FLAG_ACTIVITY_NEW_TASK`）
2. アラーム通知の `setFullScreenIntent` によるフルスクリーン表示
3. `MainActivity` の `android:showWhenLocked="true"` / `android:turnScreenOn="true"` で画面 OFF 状態でも起動・点灯

### 2.5 距離しきい値設定（F-04）

| 項目 | 値 |
|------|-----|
| デフォルト | 500 m |
| 最小 | 100 m |
| 最大 | 2000 m |
| 操作 | ステッパーで ±約 100m 単位（18 ステップ）|

### 2.6 駅名履歴（F-05）

- 追跡を開始した駅名を SharedPreferences に保存する（CSV 形式）
- 最大 5 件を保持し、超過時は最も古いものを削除する
- 同一駅名は重複して保存せず、既存を削除してから先頭に追加する（直近優先）
- アプリ再起動後も履歴は保持される

## 3. 画面仕様

### 3.1 画面遷移

```
起動
 └─ セットアップ画面
      ├─ 駅名入力 → 「開始」ボタン → [検索成功] → 追跡中画面
      │                           └─ [検索失敗] → セットアップ画面（エラー表示）
      └─ 追跡中画面 → 「停止」ボタン → セットアップ画面
```

### 3.2 セットアップ画面

画面全体がスクロール可能（Wear OS のロータリー入力・ベゼル操作対応）。

**表示要素（上から順）**

| # | 要素 | 仕様 |
|---|------|------|
| 1 | タイトル | "駅近振動通知" |
| 2 | 駅名入力フィールド | シングルライン、中央揃え、キーボード入力 |
| 3 | 検索履歴リスト | 最大 5 件のチップ一覧。タップで入力欄に反映。ハプティクスフィードバックあり |
| 4 | 距離しきい値調整 | "通知距離: XXXm" ラベル + ステッパー（+/− ボタン） |
| 5 | 開始ボタン | 駅名が空欄のとき無効化。タップでハプティクスフィードバックあり |
| 6 | エラー/情報メッセージ | 赤文字で表示（エラー時のみ）|

### 3.3 追跡中画面

**表示要素**

| # | 要素 | 仕様 |
|---|------|------|
| 1 | 時刻表示 | 画面上部（Wear OS `TimeText`） |
| 2 | プログレスリング（背景） | 常に 100%、色: ダークサーフェス |
| 3 | プログレスリング（前景） | 距離に応じて動的に変化（後述） |
| 4 | ステータスメッセージ | 距離に応じて 3 段階で変化 |
| 5 | 駅名 | 目的駅の名称 |
| 6 | 距離値 | 現在距離をメートル単位で大きく表示 |
| 7 | 停止ボタン | タップでハプティクスフィードバック → 追跡停止 |

**プログレスリング計算式**

```
進捗値 = (しきい値 × 2 − 現在距離) ÷ (しきい値 × 2)
（0〜1 の範囲にクランプ）
```

### 3.4 距離に応じた色変化

プログレスリングとステータスメッセージの色が距離に応じて変化する。

| 現在距離 / しきい値 | 色 | ステータスメッセージ |
|-------------------|----|-------------|
| > 2.0 倍 | 青 `#0066B3` | 🚄 移動中 |
| 1.0〜2.0 倍 | 緑 `#00A651` | 🚄 移動中 |
| 0.5〜1.0 倍 | オレンジ `#FFA500` | 📍 接近中... |
| ≤ 0.5 倍 | 赤 `#E94560` | 🚃 まもなく到着！ |

## 4. 通知仕様

### 4.1 通知チャネル

通知チャネルは 2 つに分離されている。重要度の異なる通知を使い分けるため。

| チャネル ID | チャネル名 | 重要度 | 用途 |
|-----------|----------|------|------|
| `station_alarm_channel` | 駅近アラームサービス | LOW | フォアグラウンドサービス常駐通知（監視中表示） |
| `station_alarm_channel_high` | 駅到着アラーム | HIGH | しきい値到達時のフルスクリーンアラーム |

### 4.2 通知の種類

**監視中通知**（追跡中、常駐）
- 通知 ID: `1`
- チャネル: `station_alarm_channel` (LOW)
- タイトル: 「駅近振動通知」
- コンテンツ: 現在距離・ステータスメッセージ
- 継続表示フラグ: ON
- タップで MainActivity を起動

**アラーム通知**（しきい値到達時、1 回のみ）
- 通知 ID: `2`（監視中通知とは別 ID）
- チャネル: `station_alarm_channel_high` (HIGH)
- フルスクリーン Intent: MainActivity を起動
- カテゴリ: `CATEGORY_ALARM`
- 優先度: `PRIORITY_HIGH`
- 自動キャンセル: ON（タップすると消える）

### 5.1 保存対象と保存先

| データ | 保存先 | フォーマット | 保存タイミング |
|--------|--------|------------|-------------|

| 現在距離 | Float? | null |
| ステータスメッセージ | String | "" |
| 追跡中の駅名 | String? | null |

## 6. 権限

| 権限 | 用途 | 取得タイミング |
|------|------|-------------|
| ACCESS_FINE_LOCATION | GPS による高精度位置情報 | 実行時（初回起動時） |
| ACCESS_COARSE_LOCATION | ネットワークベース位置情報 | 実行時（同上） |
| VIBRATE | デバイス振動 | インストール時 |
| INTERNET | Geocoder API 通信 | インストール時 |
| WAKE_LOCK | スリープ時のプロセス維持 | インストール時 |
| FOREGROUND_SERVICE | フォアグラウンドサービス | インストール時 |
| FOREGROUND_SERVICE_LOCATION | 位置情報フォアグラウンドサービス | インストール時 |
| POST_NOTIFICATIONS | 通知表示 | インストール時 |
| USE_FULL_SCREEN_INTENT | アラーム時のフルスクリーン Intent 起動 | インストール時 |
| TURN_SCREEN_ON | アラーム時に画面を点灯 | インストール時 |
| SYSTEM_ALERT_WINDOW | バックグラウンドからの Activity 起動制限の緩和 | インストール時 |

## 7. エラーハンドリング

| エラー | 処理 |
|--------|------|
| 駅名が見つからない | UI に「駅が見つかりませんでした...」を表示し追跡を開始しない |
| Geocoder 例外 | スタックトレース出力、`null` 返却として駅未発見扱い |
| 位置情報取得失敗 | リポジトリのメッセージを更新しスタックトレース出力 |
| 位置情報権限拒否 | 現バージョンでは UI フィードバックなし（権限未取得のまま追跡不可） |

## 8. 非機能要件

### 8.1 バッテリー消費

- 位置更新間隔を 3 秒（最小 1 秒）に設定し過剰な取得を抑制している
- フォアグラウンドサービス使用のため、長時間追跡時はバッテリー消費に注意が必要

### 8.2 対応言語

- UI・通知文言はすべて日本語のみ（ローカライズ非対応）
- 駅検索は `Locale.JAPAN` を使用し、日本国内の駅名のみを対象とする

## 付録: アーキテクチャ概要

```
[SetupScreen / TrackingScreen]
         ↕ collectAsState
    [MainViewModel]
     ↕ StateFlow   ↕ Intent
[StationRepository]  [StationAlarmService]
     ↕                    ↕
[SharedPreferences]  [LocationManager]
                          ↕
                 [FusedLocationProvider]
```

- **Service ↔ UI の通信**: `StationRepository` の `StateFlow` を共有する。Service が直接 ViewModel を参照しない設計。
- **永続化**: 駅名履歴のみ。追跡状態はインメモリ（アプリ終了時にリセット）。
